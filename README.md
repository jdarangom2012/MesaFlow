# MesaFlow

MesaFlow es una plataforma SaaS moderna para restaurantes desarrollada por NautilusTech S.A.S.

## Sitio Oficial

https://nautilustech.app/

## Objetivo

Automatizar la operación de restaurantes mediante:

* Pedidos QR
* Cocina en tiempo real
* POS moderno
* Dashboard operacional
* WhatsApp
* Inteligencia Artificial

## Stack Tecnológico

* Python 3.12
* Django 5
* PostgreSQL
* TailwindCSS
* HTMX
* Alpine.js
* Azure Ubuntu

## Arquitectura

* Multiempresa (Multi-Tenant)
* Cloud SaaS
* Modular
* Escalable
* Mobile First
* Responsive
* Dark Mode

## Branding

MesaFlow mantiene coherencia visual con el ecosistema NautilusTech.

## Estado del Proyecto

Fase de arquitectura, branding y UX/UI.
